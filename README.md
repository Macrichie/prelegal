# Prelegal

A legal document tool for generating, reviewing, and managing legal documents before formal legal review.

## Features

- **Document Generation** - Create legal documents from customizable templates
- **Document Review** - Review and annotate documents before engaging formal counsel
- **Document Management** - Organize, track, and manage the full document lifecycle

## Tech Stack

- **Frontend** - React / Next.js
- **Backend** - Node.js
- **Language** - TypeScript

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/prelegal.git
cd prelegal
npm install
```

### Development

```bash
npm run dev
```
